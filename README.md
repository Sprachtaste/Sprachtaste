# Sprachtaste

**Aus Ihrer Stimme wird fertiger Text.** Diktier-App für Windows und Mac.

Strg + Leertaste halten, sprechen, loslassen: Der fertige Text steht dort, wo Ihr Cursor blinkt. Als E-Mail in Outlook, als Schriftsatz in Word, als Nachricht in Teams oder als Prompt für Ihre KI.

- Rund viermal schneller als Tippen
- DSGVO-konform, verarbeitet in der EU, Server in Deutschland
- Keine Speicherung der Diktate, kein KI-Training
- Auftragsverarbeitungsvertrag mit § 203 StGB in jedem Tarif

**14 Tage kostenlos testen:** https://sprachtaste.de/download/?von=github
